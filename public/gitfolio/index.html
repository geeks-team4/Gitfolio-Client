기억나지 않는 개발 과정,

Gitfolio는 불완전한 커밋 메시지 대신 실제 코드 변경을 분석합니다.
오래된 저장소의 모든 커밋을 확인해 기능 구현, 구조 변경, 오류 수정과
트러블슈팅 과정을 기간별로 복원합니다.

커밋을 한 번에 몰아서 작성함
커밋 메시지를 "수정", "완료", "fix"처럼 불명확하게 작성함
README와 개발 문서를 체계적으로 작성하지 않음

작동 방식

레포 링크 하나만 주세요,
그 다음은 Gitfolio가 합니다

1
저장소 연결
GitHub 로그인 후 분석할 저장소와 기간을 선택합니다.
2
AI 커밋 분석
각 커밋에서 실제로 변경된 코드를 기준으로 무엇이 바뀌었는지 찾아냅니다.
3
기간별 복원
기간순으로 정렬해 트러블슈팅 포인트와 문제 해결 과정을 보여드립니다.
AI 모델 오케스트레이션

작은 변경점은 빠르게, 큰 변경점은 꼼꼼히

코드 변경량과 복잡도를 먼저 계산한 뒤 적합한 AI 모델을 자동으로 배정합니다.
복잡한 연산이 꼭 필요한 부분에서만 고급 모델을 이용해 비용 부담을 줄여드려요.

가성비 모델
오타 수정, 변수명 변경, 단순 UI 수정
중간 모델
단일 기능 구현, API 연결, 리팩터링
고급 모델
아키텍처 변경, 인증/보안 로직, 복잡한 오류 해결
개인정보 및 코드 처리

FAQ

비공개 저장소도 분석할 수 있나요?
네, 사용자가 권한을 승인한 비공개 저장소는 본인만 열람 가능한 상태로 분석됩니다.
다른 사람이 제 분석 결과를 볼 수 있나요?
아니요. 분석 결과는 기본적으로 모두 비공개이며, 외부 공개 포트폴리오 페이지는 제공하지 않습니다.
이미 분석한 저장소를 다시 보면 또 결제하나요?
동일한 분석 결과를 재조회하는 것은 추가 결제가 없습니다. 분석 범위를 확장할 때만 추가 비용이 발생합니다.
